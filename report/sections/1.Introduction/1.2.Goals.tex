\section{Goals}

The goals of this project are:

\begin{itemize}
    \item \textbf{Build a working, end-to-end streaming lakehouse pipeline, and learn how a modern streaming platform works.} Take synthetic music-streaming events from generation (Eventsim) through ingestion (Kafka), stream processing (Spark Structured Streaming), lakehouse storage (Hudi), transformation (dbt), and visualization (Superset), as a single reproducible system rather than isolated proofs of concept.
    \item \textbf{Apply the distributed-systems concepts from the course to a real system.} Exercise partitioning, replication, checkpointed exactly-once processing, and consumer-lag monitoring, so the pipeline shows the behaviors that distinguish a streaming design from a periodic batch job (Section~\ref{sec:core-theory}).
    \item \textbf{Make the whole system observable and reproducible.} Provide Prometheus/Grafana monitoring of Kafka lag and Spark resource usage, and deploy the entire stack with a single Docker Compose command.
\end{itemize}
