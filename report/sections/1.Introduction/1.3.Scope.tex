\section{Scope}

This project covers the full path from synthetic event generation to dashboarding: Eventsim, Kafka ingestion, Spark Structured Streaming into Hudi bronze tables, dbt transformation into a star schema and wide table, Superset dashboards, and Prometheus/Grafana monitoring (Chapter~\ref{ch:proposed-solution}). It also covers the distributed-systems concerns of the course -- partitioning, replication, checkpointed exactly-once processing, and consumer-lag monitoring (Section~\ref{sec:core-theory}). Everything is deployed with Docker Compose on a single machine.

Out of scope:

\begin{itemize}
    \item \textbf{Production security hardening.} Authentication, network isolation, secrets management, and TLS are not addressed; the stack is for local demonstration.
    \item \textbf{Multi-region or high-availability deployment.} The pipeline targets one machine and one region (Section~\ref{sec:proposed-cluster-setup}); failover and autoscaling are not implemented.
    \item \textbf{Real user data.} All events are synthetic, generated by Eventsim from the 10,000-song Million Song Dataset subset (Chapter~\ref{ch:problem-statement}).
\end{itemize}
